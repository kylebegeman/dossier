## Where things stand in one paragraph

Dossier 0.6.7 is a Node generator that turns one JSON model into a
self-contained interactive HTML file. Kyle decided to rebuild the core from
scratch in Go under `core/`, following the conventions of his `kore` stack and
shaped like his `corbelo` CLI, while the Node tree in `src/` keeps shipping
untouched until cutover. M0 through M6 built the core, the studio, the React
wrapper, and release tooling. Kyle then set the bar that nothing merges,
pushes, or releases until the whole product is finished, and the M7 finishing
plan closed every gap against the 0.7 spec: six designed kinds, verdicts and
a document choice, search, the accent, timelines, diagrams as SVG, the
Markdown rendition, custom kinds, the studio's remaining tools, 0.6 imports
onto the vocabularies, and a new seven-document showcase. All of it is
committed locally. Cutover and publishing stay with Kyle. The design here is
also the brand style that goes to Ledger next.

   binary, Homebrew distribution, a real self-hosting story, and Kyle's own
   stack used and refined here. Dossier does **not** adopt kore's composer,
   registry, or plugin machinery.
3. **Same repo, new directory.** `core/` beside `src/`.
4. **The name stays Dossier.** Kyle typed "Ledger" once; he meant Dossier.
5. **The design system here is the shared brand style.** Ledger
   (`/Users/kyle/Developer/active/ledger`) gets the same tokens, fonts, and
   components once this is signed off.
6. **Nothing ships half finished.** No merge, push, or release until the full
   product is done, and every kind is designed rather than permissive.
7. **Diagrams render through Graphviz compiled to wasm**, with
   `goccy/go-graphviz` vendored and patched to load lazily and cache its

8. **The studio vendors a CodeMirror 6 bundle** for its Model JSON editor,
   built outside the Go build from a lockfile and pinned by hash.

## The stack

Go 1.26, module `dossier`, stdlib `flag` and `net/http`. Dependencies:
`a-h/templ` for HTML, `yuin/goldmark` for markdown, `santhosh-tekuri/jsonschema/v6`
for schema validation, `alecthomas/chroma/v2` for build-time highlighting,
`modelcontextprotocol/go-sdk` for the `mcp` door, `modernc.org/sqlite` with
`pressly/goose/v3` for the studio store, and `goccy/go-graphviz`, vendored in
`core/third_party/go-graphviz` with a patch applied by `core/scripts/graphviz`.
Tools are pinned with `go.mod` tool directives (`templ`, `sqlc`,
`staticcheck`, `errcheck`). The studio's CodeMirror bundle is built by
`core/scripts/codemirror` and committed with its hash. `packages/react` uses
TypeScript 7 and React 19 as dev dependencies and tests with `node --test`.

## The model: five concepts

- **Kind** is a preset: the item noun, the fields items carry with their
  values and tones, the facets in order with required ones, the expected
  sections, the summary columns, how contents group, and how a reader
  decides. Six built-in kinds are designed (`brainstorm`, `plan`, `review`,
  `release`, `incident`, `brief`), described by `dossier.kind/v1`, and a team
  adds its own with `--kinds DIR`.
- **Section** has a title and either content parts or a board. Part types:
  `prose`, `spec`, `table`, `callout`, `code`, `figure`, `diagram`, `chart`,
  `timeline`.
- **Item** is a thing on a board with an id, title, one-sentence summary, the
  fields its kind declares, and facets. Board layout `rows` means unnumbered
  entries.
- **Facet** is a labeled markdown body, checked against the kind's order.
  Only Risk renders ochre.
- **Decisions** are the only state: the choice (`path`), picks or verdicts by
  id, and notes. A kind may ask a question first, and a document's `choice`
  replaces it. A kind may guard a choice, as release does for shipping over a
  failed required gate.

## Rules the library enforces

- **Effort is agent time, never calendar time.** `S` under an hour, `M` a few
  hours with review, `L` a day or more across sessions. This came from Kyle
  directly: building is fast now; what varies is model and tokens.
- **Concise by default.** One-sentence summaries, two- or three-sentence
  facets. Kinds carry character limits reported as **warnings** by `validate`
  and `build`. Warnings never block a build.
- **Detail sits behind a fold.** Items render collapsed.
- **The artifact makes zero external requests** unless `meta.fonts: "google"`.
- **Budgets are tests.** Reader runtime at most 20 KB (19.2 KB now),
  stylesheet at most 30 KB (29.1 KB now), each showcase page at most 120 KB
  built (the largest is the flagship, under 100 KB).
- **The showcase is a fixture set.** Every document in `core/examples`
  builds with no findings or warnings and matches its HTML and Markdown
  goldens.

## Gotchas learned the hard way

- **templ cannot evaluate expressions inside `<style>` or `<script>`.** The
  stylesheet, the model island, and the reader script are assembled as
  strings in `render.go` and emitted with `templ.Raw`.
- **errcheck rejects bare `fmt.Fprintf` to an `io.Writer`.** Use the `say` and
  `sayln` helpers in `internal/doors/doors.go`.
- **staticcheck ST1005:** error strings must not end with punctuation.
- **errcheck flags `defer x.Close()`.** Write `defer func() { _ = x.Close() }()`.
- **`make check` fails while generated output is untracked or dirty.** That
  covers `*_templ.go`, `skill/SKILL.md`, and the React model types; commit
  them with the change.
- **Piping `make check` through `grep | tail` hides its exit status.** Check
  `$?` or redirect to a file first.
- **go vet:** a non-constant format string in a printf-style wrapper is an
  error; write `say(w, "%s", x)`.
- **Inside an SVG, CSS font sizes are in layout units.** Diagram labels stay
  at the sizes Graphviz laid out; the root size in pixels sets how large they
  show.
- **Grid and flex items grow to their longest unbreakable content.** Phone
  grids use `minmax(0, 1fr)`, text may break anywhere, and tables keep their
  words whole inside their own scroll frame.
- **The in-app browser opens new local file paths only with approval,** and
  shows them as static snapshots in a new tab on every load. Reuse a path it
  has opened, or serve over loopback. Its screenshots can lag a scroll by one
  step.
- **Headless Chrome paints nothing after a scroll in `--screenshot` mode,**
  and its window is at least 485 pixels wide. For a scrolled capture, drive
  it over the DevTools protocol: set the metrics, navigate, scroll, then
  `Page.captureScreenshot`. Stop the process you started.
- **`make dist` replaces all of `core/dist`.** Keep QA output, such as
  built pages and studio copies, outside it, in a scratch directory.
- **A hidden tab runs no animation frames.** The in-app browser keeps its
  tabs hidden, so a dialog's close event and CodeMirror's lint markers wait
  until the tab is shown. The studio settles its dialogs without waiting for
  the event; check the markers with the pane visible.
- **Headless Chrome follows the system theme.** Pass
  `--blink-settings=preferredColorScheme=1` for light, or emulate
  `prefers-color-scheme` over the protocol.
