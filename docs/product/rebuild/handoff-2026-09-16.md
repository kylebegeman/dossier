# Dossier 0.7 rebuild handoff

## Where things stand in one paragraph

Dossier 0.6.7 is a Node generator that turns one JSON model into a
self-contained interactive HTML file. It grew bloated across the 0.5 and 0.6
arcs. Kyle decided to rebuild the core from scratch in Go under `core/`,
following the conventions of his `kore` stack and shaped like his `corbelo`
CLI, while the Node tree in `src/` keeps shipping untouched until cutover.
Milestones M0 through M3 are done and committed, plus two rounds of design
polish. The design being finalized here is also the brand style that will be
applied to Ledger next.

## Decision history, so it is not reopened

1. **Rebuild, not reshape.** All twelve moves from the 0.7 brainstorm are in
   scope. Kyle picked the rebuild path: a new core beside the old tree, cut
   over when every example builds through it, then delete the old tree.
2. **Go, on the kore conventions, shaped like corbelo.** Not TypeScript. The
   reasons: one CGO-free static binary, Homebrew distribution, a real
   self-hosting story, and Kyle wants his own AI-optimized stack used and
   refined here. `kore` is a convention reference and a future source of
   copy-in capabilities; Dossier is a standalone module and does **not**
   adopt kore's composer, registry, or plugin machinery.
3. **Same repo, new directory.** `core/` beside `src/`.
4. **The name stays Dossier.** Kyle typed "Ledger" once; he meant Dossier.
5. **The design system here is the shared brand style.** Ledger
   (`/Users/kyle/Developer/active/ledger`, a TypeScript project) gets the
   same tokens, fonts, and components once this is signed off.

## The stack

Go 1.26, module `dossier`, stdlib `flag` and `net/http`. Dependencies:
`a-h/templ` for HTML, `yuin/goldmark` for markdown, `santhosh-tekuri/jsonschema/v6`
for schema validation, `alecthomas/chroma/v2` for build-time highlighting.
`modelcontextprotocol/go-sdk` for the `mcp` door. Planned for M6:
`modernc.org/sqlite`, `pressly/goose`, `sqlc` for serve. Tools are pinned with
`go.mod` tool directives (`templ`, `staticcheck`, `errcheck`).

## The model: five concepts

- **Kind** is a preset naming the facets items carry, the field vocabularies,
  the summary table columns, how contents group, and the closing pick text.
  `brainstorm` carries the full vocabulary; `plan`, `review`, `release`,
  `incident`, and `brief` are permissive presets pending their vocabularies.
- **Section** has a title and either content parts or a board. Part types:
  `prose`, `spec`, `table`, `callout`, `code` (highlighted), `figure`,
  `diagram` (source only), `chart`.
- **Item** is a numbered thing in a board with id, title, summary, size,
  effort, impact, dependsOn, facets. Board layout `rows` means unnumbered
  also-considered entries.
- **Facet** is a labeled markdown body, validated against the kind's fixed
  order. Risk and Note render with the ochre label.
- **Decision** is the only state: path, picked ids, notes by id.

## Rules the library enforces

- **Effort is agent time, never calendar time.** `S` under an hour, `M` a few
  hours with review, `L` a day or more across sessions. No days-of-work or
  weeks-of-work language in presets, examples, docs, or the skill. This came
  from Kyle directly: building is fast now; what varies is model and tokens.
- **Concise by default.** One-sentence summaries, two- or three-sentence
  facets. Kinds carry character limits (160 and 420 for brainstorm) reported
  as **warnings** in the result envelope by `validate` and `build`. Warnings
  never block a build.
- **Detail sits behind a fold.** Items render collapsed.
- **The artifact makes zero external requests** unless `meta.fonts: "google"`.
- **Budgets are tests.** Reader runtime at most 20 KB (currently 11 KB),
  stylesheet at most 30 KB (currently 20 KB), artifact under 120 KB
  (currently 94 KB).

## Gotchas learned the hard way

- **templ cannot evaluate expressions inside `<style>` or `<script>`.** The
  stylesheet, the model island, and the reader script are assembled as
  strings in `render.go` and emitted with `templ.Raw`.
- **`make check` fails if generated `*_templ.go` is dirty in git.** Run
  `make generate` and commit the output.
- **errcheck rejects bare `fmt.Fprintf` to an `io.Writer`.** Use the `say` and
  `sayln` helpers in `internal/doors/doors.go`.
- **staticcheck ST1005:** error strings must not end with punctuation.
- **errcheck flags `defer x.Close()`.** Write `defer func() { _ = x.Close() }()`.
- **`make check` fails while generated output is untracked or dirty.** That
  covers `*_templ.go` and `skill/SKILL.md`; commit them with the change.
- **Piping `make check` through `grep | tail` hides its exit status.** Check
  `$?` or redirect to a file first.
- **go vet:** a non-constant format string in a printf-style wrapper is an
  error; write `say(w, "%s", x)`.
- **The in-app browser preview serves stale snapshots of local files** and
  disables `localStorage` on `data:` URLs. To look at a rebuilt artifact,
  write it under a fresh filename or close and reopen the tab, and verify
  persistence by reading the code rather than in the pane.
