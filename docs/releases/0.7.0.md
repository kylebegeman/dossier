Dossier 0.7.0 is a rebuild. One Go binary replaces the Node generator, six designed kinds replace dozens of block types, and every decision a reader makes comes back as one line an agent can apply.

![A Dossier page: Ten moves for a calmer winter crossing](https://raw.githubusercontent.com/kylebegeman/dossier/v0.7.0/docs/assets/readme/hero-light.webp)

**[Open the live examples](https://kylebegeman.github.io/dossier/)**, one for every kind.

## Highlights

- **Six designed kinds.** Brainstorm, plan, review, release, incident, and brief each carry their own fields, facets, sections, and way to decide. Teams add their own with `--kinds DIR`.
- **Decide by number.** Picks, verdicts, and a document choice all write one reply line, such as `rework, fix 1, 2; later 4.`, which `dossier decisions apply` reads back into the model.
- **A better page.** Search, verdicts from the keyboard, timelines, charts, one brand color, and diagrams from DOT or Mermaid laid out as SVG at build time, still in one file with no external requests.
- **The studio.** `dossier serve` edits the page in place as drafts, keeps decisions in step across tabs, imports replies, and edits the model as JSON in CodeMirror.
- **For agents.** One command catalog drives the CLI, an MCP server, and a generated skill, all answering one result envelope.
- **Markdown too.** `dossier build --md` writes a copy for pull requests and wikis.

## Install

```sh
brew install kylebegeman/tap/dossier
```

```sh
npm install --save-dev @kylebegeman/dossier
```

Or download the archive for your platform below. Each carries the binary, the license, and third-party notices.

## Upgrading from 0.6

- 0.6 documents still validate and build, with a warning for each old block. `dossier upgrade FILE` rewrites them onto the new kinds.
- The npm package now installs the binary for your platform, and the 0.6 JavaScript API is gone. `@kylebegeman/dossier@0.6.7` stays on npm for projects that need it.
- The Homebrew formula installs the binary and no longer needs Node.

`release-0-7-0.html`, attached below, is this release's own release document: the gates it passed, built with Dossier.
