Dossier 0.7.1 makes deciding easier to follow. The block at the bottom of a page is now Your reply: calm, compact, and clear that it fills in from your choices, with every reply said back in plain words. The showcase now opens with a brainstorm about a codebase.

![A Dossier page: Ten changes for a steadier booking service](https://raw.githubusercontent.com/kylebegeman/dossier/v0.7.1/docs/assets/readme/hero-light.webp)

**[Open the live examples](https://kylebegeman.github.io/dossier/)**, led by a brainstorm about a booking service's code.

## Changes

- **Your reply.** The saturated block at the bottom of a deciding page is now a bordered section that says what it is: it fills in as you decide, and you paste it back to your agent. Until you decide, it shows an example; after, your reply with Copy reply and Copy as JSON.
- **Replies in plain words.** Under the reply line, the page says it plainly: `safety, 2, 10.` reads as "Choice: Safer changes. Pick: ideas 2 and 10." Go and the reader share the wording, and one set of test cases holds both.
- **A code-first showcase.** [Ten changes for a steadier booking service](https://kylebegeman.github.io/dossier/booking-service.html) leads the examples, with the request path as a diagram, the Go behind a slow step, and changes that name the files they touch. [Small fixes before the spring timetable](https://kylebegeman.github.io/dossier/spring-fixes.html) shows the same kind without code, and the winter crossing page stays at its old address.
- **Fixes.** A note that ends with a period no longer doubles it in the reply line, and a note that ends with ! or ? ends the line itself. The counts in the masthead link to the reply block. On a page where no item can take a verdict, the example reply keeps only the choice. The Markdown copy says "No decisions yet." for an empty set of decisions. The last section above the reply block no longer draws a rule, and code blocks indent tabs four columns wide.

## Install

```sh
brew install kylebegeman/tap/dossier
```

```sh
npm install --save-dev @kylebegeman/dossier
```

Or download the archive for your platform below. `brew upgrade dossier` and `npm install @kylebegeman/dossier@latest` move an existing install to 0.7.1, and models from 0.7.0 build unchanged.

`release-0-7-1.html`, attached below, is this release's own release document: the gates it passed, built with Dossier.
