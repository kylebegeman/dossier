Dossier 0.7.2 is a maintenance release. Pages, the reader, the studio, and every command behave exactly as in 0.7.1. What changes is how Dossier reaches npm: all eight packages now publish from this repository's release workflow through npm trusted publishing, each version with signed provenance, and none of them accepts a publish token.

![A Dossier page: Ten changes for a steadier booking service](https://raw.githubusercontent.com/kylebegeman/dossier/v0.7.2/docs/assets/readme/hero-light.webp)

**[Open the live examples](https://kylebegeman.github.io/dossier/)**, led by a brainstorm about a booking service's code.

## Changes

- **Trusted publishing on npm.** `@kylebegeman/dossier`, `@kylebegeman/dossier-react`, and the six platform packages publish only from `.github/workflows/release.yml` when a version is tagged. npm checks that workflow instead of a token, and after installing you can confirm each package's provenance with `npm audit signatures`.

## Install

```sh
brew install kylebegeman/tap/dossier
```

```sh
npm install --save-dev @kylebegeman/dossier
```

Or download the archive for your platform below. Moving from 0.7.1 is optional, since nothing else changed: `brew upgrade dossier` or `npm install @kylebegeman/dossier@latest` when convenient.

`release-0-7-2.html`, attached below, is this release's own release document: the gates it passed, built with Dossier.
